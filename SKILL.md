# Portfolio Art Direction

This portfolio must feel like an independent European creative studio.

Core characteristics:

- editorial
- minimal
- confident
- experimental
- premium
- typography-driven

## Avoid

Never use:

- generic SaaS cards
- purple gradients
- excessive border radius
- glassmorphism
- floating 3D blobs
- generic dashboard UI
- unnecessary pills
- excessive shadows
- repetitive fade-up sections
- generic AI copy

## Typography

Use typography as a graphical element.

Mix:

modern grotesk
+
high contrast editorial serif

Huge display typography is encouraged.

Use extreme size contrast between headlines and metadata.

## Layout

Prefer:

asymmetry
overlapping elements
large negative space
editorial grids
full-bleed imagery

Avoid symmetrical section-after-section layouts.

## Images

Photography should feel like:

fashion editorial
creative director portrait
modern European studio campaign

Never use generic corporate imagery.

## Motion

Use motion selectively.

Hero:
strong orchestrated reveal

Projects:
mask reveals
subtle parallax
cursor interactions

Other sections:
minimal movement

## Mobile

Mobile is a separate composition.

Do not simply stack desktop sections.

The iPhone layout should feel like a premium editorial magazine.
